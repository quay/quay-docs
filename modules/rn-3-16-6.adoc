[id="bug-fixes-316-6"]
== {productname} 3.16.6 bug fixes

* link:https://issues.redhat.com/browse/PROJQUAY-13135[*PROJQUAY-13135*]. Previously, {productname} could generate excessive DNS query bursts that saturated the local resolver.
+
With this release, DNS query patterns are improved so that local resolvers are less likely to become saturated.

* link:https://issues.redhat.com/browse/PROJQUAY-12801[*PROJQUAY-12801*]. Previously, orphaned multipart uploads were not cleaned up as part of blob cleanup work and could remain in object storage.
+
With this release, orphaned multipart uploads are cleaned up during blob cleanup.

* link:https://issues.redhat.com/browse/PROJQUAY-12410[*PROJQUAY-12410*]. Previously, when an organization name contained the word `organization`, the V2 UI generated malformed API requests.
+
With this release, V2 UI routing handles organization names that contain `organization` correctly.

* link:https://issues.redhat.com/browse/PROJQUAY-11682[*PROJQUAY-11682*]. Previously, the Autopruner matched on `.sig` tags instead of filtering them out.
+
With this release, the Autopruner filters `.sig` tags and no longer matches them for pruning.
