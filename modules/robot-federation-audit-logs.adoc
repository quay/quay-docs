= Audit log events for robot API tokens and federation

[role="_abstract"]
{productname} records an audit log event for every robot API token and robot federation operation. Review these events in the *Logs* tab of the organization in the v2 UI, or retrieve them from the usage logs endpoint.

.Audit log events
[cols="2a,3a",options="header"]
|===
|Event |Recorded when

|`create_robot_api_token`
|A robot API token is created.

|`revoke_robot_api_token`
|A robot API token is revoked.

|`create_robot_federation`
|A robot federation entry is created or updated.

|`delete_robot_federation`
|All federation entries for a robot account are cleared.

|`federated_robot_token_exchange`
|An external token is presented at the `POST /sts/token` endpoint. Both successful and failed exchanges are recorded. Early exchange failures occurring before robot identification, such as malformed requests or unverified tokens, are logged system-wide, while scope rejections and successful exchanges show in the *Logs* tab of the organization.
|===

To retrieve these events for an organization, use the `GET /api/v1/organization/{orgname}/logs` endpoint:

[source,terminal]
----
$ curl -X GET "https://<quay-server.example.com>/api/v1/organization/<organization_name>/logs" \
  -H "Authorization: Bearer <access_token>"
----
