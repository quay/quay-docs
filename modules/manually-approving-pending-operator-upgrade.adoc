= Manually approving a pending Operator upgrade

[role="_abstract"]
To approve a pending {productname} Operator upgrade when using `Manual` approval, open the *Subscription* tab, review the install plan and resources, and click Approve. You can then monitor the upgrade progress on the Installed Operators page.

If you are upgrading to {productname} {producty} and your config bundle contains a customized `DATA_MODEL_CACHE_CONFIG` with managed Redis, prepare the cache configuration before or after approving the InstallPlan, depending on the option that you choose. Removing the custom configuration can happen before approval. Setting `cache.managed: false` requires the {producty} Operator and CRD and cannot be applied to the 3.18 CRD.
