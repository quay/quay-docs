= Listing robot API tokens

[role="_abstract"]
To review which robot API tokens exist for a robot account, their scopes, and when they expire, you can use the v2 UI or the {productname} management API.

.Prerequisites

* You have enabled the `FEATURE_ROBOT_API_TOKENS` configuration field.
* You have created at least one robot API token.

.Procedure

. To list tokens by using the UI:
+
.. On the v2 UI, click *Organizations* and then click the name of your organization.
+
.. Click the *Robot accounts* tab, then click the name of your robot account.
+
.. Click the *API Tokens* tab. Each token is listed with its name, its scopes, its expiry as a UTC timestamp, and the user who created it.
+
[NOTE]
====
The *API Tokens* tab does not show when a token was last used. To retrieve the `last_accessed` value, use the API. The *Last accessed* column on the *Robot accounts* tab applies to the robot account, not to an individual token.
====

. To list tokens by using the API, enter the following command:
+
[source,terminal]
----
$ curl -X GET "https://<quay-server.example.com>/api/v1/organization/<organization_name>/robots/<robot_shortname>/tokens" \
  -H "Cookie: <session_cookie>" \
  -H "X-CSRF-Token: <csrf_token>"
----
+
.Example output
[source,json]
----
[
  {
    "uuid": "a1b2c3d4-0000-0000-0000-000000000000",
    "name": "ci-pipeline",
    "scope": "repo:read user:read",
    "expires_at": "Wed, 14 Jan 2026 12:00:00 -0000",
    "created": "Mon, 15 Dec 2025 12:00:00 -0000",
    "created_by": "quayadmin",
    "last_accessed": "Tue, 16 Dec 2025 09:31:12 -0000"
  }
]
----
+
[NOTE]
====
The list response never includes the token value. Record the value when you create the token.
====
