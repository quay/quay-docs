== MySQL and MariaDB support removed

Support for MySQL and MariaDB as the {productname} database backend has been removed in {productname} {producty}. MySQL and MariaDB were deprecated in {productname} 3.6 and have not received additional features or explicit testing coverage since that release.

PostgreSQL is the only supported database backend for {productname} {producty}. Before upgrading, migrate your database to PostgreSQL if you have not already done so.
