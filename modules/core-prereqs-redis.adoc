= Redis backend

[role="_abstract"]
{productname} uses Redis to support backend tasks such as live builder logs, user events, and the locking mechanism that is required for garbage collection. Redis data is ephemeral.

You do not need high availability for Redis because the data is not persistent. If Redis fails, you will lose access to build logs, builders, and the garbage collector service. Additionally, user events will be unavailable.

For geo-replication, a single Redis cache is shared across the entire {productname} setup and must be accessible by all {productname} pods.

You can use a Redis image from the Red Hat Software Collections or from any other source you prefer.
