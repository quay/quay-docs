== Operator-managed read-only mode

With {productname} {producty}, the {productname} Operator supports an Operator-managed read-only lifecycle for application-consistent backups. Previously, enabling read-only mode required manually creating service keys, modifying the configuration secret, and scaling the Operator deployment. Now, administrators can set `spec.readOnly: true` on the `QuayRegistry` custom resource to transition the registry into read-only mode. The Operator handles service key creation and rotation, configuration rendering, deployment restarts, and HPA management automatically.
