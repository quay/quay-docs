= Creating a robot API token by using the UI

[role="_abstract"]
To let a robot account call the {productname} management API with an expiring, scoped credential, you can create a robot API token in the v2 UI. The token value is displayed once.

.Prerequisites

* You have enabled the `FEATURE_ROBOT_API_TOKENS` configuration field.
* You have created an organization and a robot account.
* You have logged in as a user who can administer the organization.

.Procedure

. On the v2 UI, click *Organizations*.

. Click the name of your organization, for example, `test-org`.

. Click the *Robot accounts* tab.

. Click the name of your robot account. The credentials dialog opens on the *Robot Account* tab, which holds the static push and pull token of the robot.

. Click the *API Tokens* tab.

. Click *Create API token*.

. In the *Create robot API token* dialog, enter the following information:
+
* *Token name*: A name for the token, for example, `ci-pipeline`.
* *Expiration*: `7 days`, `30 days`, or `90 days`. The default is `30 days`.
* *Scopes*: Select at least one scope, for example, *View all visible repositories* and *Read User Information*.
+
[NOTE]
====
*Create* stays disabled until you have entered a name and selected at least one scope. You are offered only the scopes that you hold yourself.
====

. Click *Create*. The *Robot API token created* dialog shows the token value.
+
[IMPORTANT]
====
The token value is displayed only once. Copy it before you close the dialog. You cannot retrieve it afterwards.
====

. Copy the token value, then click *Done*.

.Verification

* On the *API Tokens* tab, confirm that the token is listed with its name, its scopes, its expiry as a UTC timestamp, and the user who created it.
