= Revoking a robot API token

[role="_abstract"]
To withdraw a robot account's access to the {productname} management API before its token expires, you can revoke the token. Revocation takes effect immediately.

.Prerequisites

* You have created a robot API token.

.Procedure

. On the v2 UI, click *Organizations* and then click the name of your organization.

. Click the *Robot accounts* tab, then click the name of your robot account.

. Click the *API Tokens* tab.

. Revoke the token using one of the following methods:
+
** For a single token, click *Revoke* at the end of the row for the token you want to remove.
+
[WARNING]
====
Single-row revocation takes effect immediately without a confirmation prompt. The token stops working immediately and its entry is removed from the table.
====
+
** For multiple tokens, select the checkbox next to each token you want to remove and click *Revoke selected* above the table. Type `confirm` in the modal dialog when prompted to complete the revocation.

. To revoke a token by using the API, enter the following command:
+
[source,terminal]
----
$ curl -X DELETE "https://<quay-server.example.com>/api/v1/organization/<organization_name>/robots/<robot_shortname>/tokens/<token_uuid>" \
  -H "Cookie: <session_cookie>" \
  -H "X-CSRF-Token: <csrf_token>"
----

.Verification

* Call the management API with the revoked token by entering the following command:
+
[source,terminal]
----
$ curl -X GET "https://<quay-server.example.com>/api/v1/user/" \
  -H "Authorization: Bearer <qro_token>"
----
+
The request returns `401`.
