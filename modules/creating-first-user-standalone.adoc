= Creating the first user on a standalone registry

[role="_abstract"]
To create the first user account on a standalone {productname} registry, you can open the UI and complete *Create Account*. You can then log in from the CLI to confirm access.

.Prerequisites

* You have deployed a proof of concept, standalone, or high availability {productname} registry.
* You can reach the registry UI, for example, `\http://quay-server.example.com`.

.Procedure

. Open the {productname} UI in a browser.

. Click *Create Account*.

. Enter the details for *Username*, *Password*, *Email*, and then click *Create Account*. After creating the first user, you are automatically logged in to the Project Quay registry.
