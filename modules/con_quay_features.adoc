[id="quay-features"]
= {productname} features

[role="_abstract"]
{productname} provides enterprise registry capabilities for storing, distributing, securing, and automating container images and OCI artifacts. The following features highlight common capabilities for current releases. The list is not exhaustive; see the {productname} release notes for the latest information.

[id="quay-features-ha"]
== Scalability and high availability

{productname} can run as a highly available registry on premise or in the cloud. You can scale deployments to handle significant image traffic while keeping the registry available for development and production workloads.

[id="quay-features-content-distribution"]
== Content distribution

{productname} helps you deliver images in multiple ways:

* *Repository mirroring*. Synchronize images from {productname} or other registries into your {productname} deployment based on repository names and tags.
* *Geo-replication*. Present multiple geographically distributed {productname} deployments as a single registry, with asynchronous replication and transparent client failover.
* *Disconnected environments*. Deploy {productname} in air-gapped or partially connected environments when you need registry access without full internet connectivity.

[id="quay-features-security"]
== Security and access control

{productname} includes Clair for vulnerability scanning of container images, with insights into known issues and suggested remediation. You can also configure TLS, isolate build workloads, and use organization and team role-based access controls to manage who can view or change registry content.

[id="quay-features-automation"]
== Build and CI/CD automation

{productname} integrates with Continuous Integration/Continuous Deployment (CI/CD) tools and Git-compatible systems. You can automate image builds and deployments, including build triggers such as GitHub webhooks when code is committed.

[id="quay-features-image-support"]
== Image and artifact support

{productname} stores and distributes container images and other OCI artifacts. It supports Docker v2, schema 2, including multi-architecture images, so teams can manage diverse workloads in one registry.

[id="quay-features-operations"]
== Day-2 operations

{productname} includes operational capabilities such as custom log rotation and zero-downtime garbage collection. Red Hat provides 24/7 support for {productname}.
