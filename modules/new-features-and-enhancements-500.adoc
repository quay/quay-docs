[id="oidc-superuser-group-sync-500"]
== OIDC superuser group synchronization

* {productname} {producty} introduces superuser group synchronization for OIDC-backed deployments, providing feature parity with `LDAP_SUPERUSER_FILTER`. Two new optional fields, `SUPERUSER_GROUP` and `GLOBAL_READONLY_SUPERUSER_GROUP`, are now supported inside any OIDC login service config block. Users in the configured OIDC groups are automatically granted or revoked superuser or global read-only superuser privileges at each login, based on their current OIDC group membership. This feature operates independently of `FEATURE_TEAM_SYNCING` and does not affect users who are statically listed in the `SUPER_USERS` configuration field.

[id="configurable-gunicorn-worker-timeout"]
== Configurable gunicorn worker timeout

* {productname} {producty} introduces configurable gunicorn worker timeout settings. Two new `config.yaml` parameters, `GUNICORN_REGISTRY_TIMEOUT` and `GUNICORN_WEB_TIMEOUT`, allow administrators to increase the gunicorn worker timeout beyond the previous hardcoded 30-second default. 
+
Increasing these values prevents worker termination during long-running operations, including large image pushes, proxy cache blob downloads, and API queries on large organizations with quota enabled. The default values are `300` seconds for the registry process and `60` seconds for the web process. The minimum accepted value for both parameters is `30` seconds and the maximum is `300` seconds.
