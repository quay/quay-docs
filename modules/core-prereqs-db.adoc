= Database backend

[role="_abstract"]
The {productname} database backend stores registry metadata such as users, organizations, images, and tags. PostgreSQL is the preferred database for {productname} and Clair.

Deploying {productname} in a highly available (HA) configuration requires that your database services are provisioned for high availability. If {productname} is running on public cloud infrastructure, use the PostgreSQL services that your cloud provider offers. PostgreSQL includes the features needed to support Clair security scanning.

When you use Clair vulnerability scanning, plan a separate PostgreSQL database for Clair. Do not use the same PostgreSQL database for both {productname} and Clair. The Operator can manage a Clair database (`clairpostgres`), or you can provision Clair's database yourself.

Geo-replication requires a single, shared database that is accessible from all regions.
