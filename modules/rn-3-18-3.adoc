[id="bug-fixes-318-3"]
== {productname} 3.18.3 bug fixes

* link:https://issues.redhat.com/browse/PROJQUAY-14327[*PROJQUAY-14327*]. Previously, build triggers could fail when creating GitHub deploy keys because {productname} generated RSA 2048 keys and GitHub now requires RSA keys of at least 3072 bits.
+
With this release, generated GitHub deploy keys use RSA 3072. As a result, build trigger setup succeeds against current GitHub key requirements.

* link:https://issues.redhat.com/browse/PROJQUAY-14106[*PROJQUAY-14106*]. Previously, repository notification status and event filters on the notifications table did not filter the displayed results.
+
With this release, notification status and event filters apply to the table correctly. As a result, the notifications list shows only matching rows.

* link:https://issues.redhat.com/browse/PROJQUAY-13381[*PROJQUAY-13381*]. Previously, the notification bell badge capped the displayed unread count at 5.
+
With this release, the notification badge no longer incorrectly limits the unread count to 5. As a result, the badge reflects the actual unread notification count.
