= Keyless authentication with robot accounts

[role="_abstract"]
With keyless authentication in {productname}, you can exchange an OIDC token for a short-lived robot account token that expires after one hour.

In previous versions of {productname}, robot account tokens were valid for the lifetime of the token unless deleted or regenerated. Tokens that do not expire have security implications for users who do not want to store long-term passwords or manage the deletion or regeneration of authentication tokens.

Keyless authentication reduces the risk of robot token exposure by removing exchanged tokens after one hour.

Configuring keyless authentication with robot accounts is a multi-step procedure that requires setting a robot federation, generating an OAuth2 token from your OIDC provider, and exchanging the OAuth2 token for a robot account access token.

A robot federation entry can grant two different kinds of access:

Registry access:: The exchanged token can push and pull images through the Docker v2 endpoints. This is the default when a federation entry carries no management API scopes.
Management API access:: The exchanged token can also call the {productname} management API, limited to the scopes that the federation entry allows. This requires the `FEATURE_ROBOT_API_TOKENS` and `FEATURE_ROBOT_API_TOKEN_EXCHANGE` configuration fields, and uses the `POST /sts/token` endpoint rather than the registry login endpoint.

The procedures that follow configure registry access. For management API access, see the additional resources.
