= View your first Clair scan
:context: view_your_first_clair_scan

[role="_abstract"]
When I have pushed an image, I want to open the Clair vulnerability report in the UI, so that I know security scanning works in my registry. Quay.io and Operator-managed registries typically include Clair by default; standalone proof-of-concept and high availability deployments require Clair to be deployed first.
