= Quay JTBD documentation preview

This directory is a Jobs-to-be-Done (JTBD) reorganization of {productname} documentation for Surge PR previews.

== Layout

Each product documentation category is a book:

* `master.adoc` — category book that includes every job assembly
* `*-job-slug*.adoc` — one assembly per JTBD job (title, job statement abstract, module includes)
* `_attributes/attributes.adoc` — symlink to the repo-wide attributes file
* `modules/` — symlink to `../../modules`
* `images/` — symlink to `../../images`

Category order and module placement come from `JTBD draft 11.pre-gapfill.xlsx`.

== Preview URLs

After `build_docs` runs, each category is available as:

* `/quay_jtbd-<category>/` (directory index)
* `/quay_jtbd-<category>.html` (flat HTML for `welcome.adoc` xrefs)

Legacy books remain at their existing paths for comparison.
